## Requirements

- A fresh or existing **NixOS** install (unstable channel)
- A copy of your own `hardware-configuration.nix` (generated by the NixOS
  installer at `/etc/nixos/hardware-configuration.nix`)
- An internet connection during the first build — a few packages (swww,
  waypaper, wallust) are fetched fresh rather than from a binary cache

## Quick start

```bash
curl -fsSL https://raw.githubusercontent.com/0xhealer/hypr-nix-dots/main/bootstrap.sh | bash
```

What it does, in order:

1. Enables `nix-command` and `flakes` experimental features
2. Clones this repo to `~/.local/share/hypr-nix-dots`
3. Copies your existing `/etc/nixos/hardware-configuration.nix` in
4. Stages everything for the flake and runs
   `nixos-rebuild switch --flake .#nixos`
5. Reboots automatically 10 seconds after a successful build (Ctrl+C to
   cancel and reboot manually later)

The script is safe to re-run.

After rebooting, pick the **Hyprland** session at the SDDM login screen,
then open **Waypaper** and select a wallpaper once — that's what seeds the
whole color palette (details below).

## Color theming — how it actually works

Waypaper's `post_command` (see `home/desktop/tools.nix`) runs `wallust run`
on whatever wallpaper you pick. wallust reads the templates in
`home/style/wallust.nix` and rewrites:

- `~/.config/waybar/colors.css`
- `~/.config/kitty/colors.conf`
- `~/.config/rofi/colors.rasi`
- `~/.config/dunst/dunstrc`
- `~/.config/hypr/colors.conf`

These five files are deliberately **not** managed via home-manager's
`xdg.configFile`, which would make them read-only symlinks that wallust
couldn't overwrite at runtime. Instead, a `home.activation` script seeds
them once — with a specific dark palette baked in — the first time you run
`home-manager switch` / `nixos-rebuild switch`, and wallust owns them from
then on. Re-running the rebuild never clobbers whatever wallust has
generated since.

Dunst is launched via Hyprland's `exec-once` rather than home-manager's
`services.dunst`, for the same reason — its config needs to stay writable.
If Dunst's colors look stale after a wallpaper change, restart it
(`killall dunst; dunst &`, or just re-login).

## Blur & transparency

Set in `home/desktop/hyprland.nix`:

- `blur.size = 8`, `blur.passes = 4`, `new_optimizations = true`
- `active_opacity = 0.92`, `inactive_opacity = 0.85`
- Per-app overrides via `windowrulev2` (Kitty and Thunar get their own
  opacity levels)
- Kitty additionally uses `background_opacity = 0.85` with
  `dynamic_background_opacity` on, so it react to wallust's live-generated
  background color too

## Layout

```
flake.nix                    nixpkgs, home-manager, vscode-extensions inputs
bootstrap.sh                 one-shot installer (ends by rebooting)
hosts/nixos/default.nix      host entry point, user account

modules/                     system-level NixOS config
  display.nix                 SDDM, programs.hyprland, polkit agent
  audio.nix                   PipeWire
  network.nix                 NetworkManager, firewall, Tailscale trust
  system.nix                  boot, locale, misc system settings
  services.nix                 SSH, gvfs, etc.
  virtualisation.nix           Docker

home/
  default.nix                 home-manager entry point
  packages.nix                 general-purpose home.packages

  desktop/
    hyprland.nix                the compositor config itself
    hyprlock.nix                lock screen
    hypridle.nix                idle/suspend daemon
    wlogout.nix                 power menu
    waybar.nix                  status bar
    rofi.nix                    app launcher
    dunst.nix                   notifications (package only — see above)
    shell.nix                   imports rofi.nix + dunst.nix
    tools.nix                   cliphist, swappy, waypaper config.ini

  style/
    wallust.nix                 wallust config + templates + seeding activation script
    gtk.nix                     adw-gtk3 theme, candy-icons, Bibata-Modern-Ice cursor — all nixpkgs-native

  apps/                        terminal tools, editor (kitty), git, vscode,
                                media, fish shell, fastfetch, neovim, starship
```

## Customizing

- **Wallpapers**: drop images into `assets/wallpapers/`, or point Waypaper
  at any folder — `home/desktop/tools.nix` sets the default.
- **Seed palette**: the exact hex values used to seed Waybar/Kitty/Rofi/
  Dunst/Hyprland before wallust ever runs live in
  `home/style/wallust.nix` (`home.activation.seedWallustTargets`).
- **Monitor layout**: `home/desktop/hyprland.nix` → `settings.monitor`.
- **Keybinds**: same file, `settings.bind` / `binde` / `bindl` / `bindm`.
- **Blur/opacity values**: same file, `settings.decoration`.

## Troubleshooting

**Build fails with `'<package>' has been renamed to/replaced by '<newname>'`.**
nixpkgs unstable periodically renames packages (this repo has already hit
`qt6ct` → `qt6Packages.qt6ct` and `rofi-wayland` → merged into `rofi`).
Not a bug in this config — just update the package reference to whatever
name the error says it's now called, in the file the error trace points to.

**`hypridle` doesn't seem to start.** It runs as its own systemd user
service rather than via `exec-once`, which occasionally doesn't fire
without a session manager like UWSM. If it's not idling/locking, add
`"hypridle"` to the `exec-once` list in `home/desktop/hyprland.nix` as a
manual fallback.

**Dunst notification colors look stale after changing wallpaper.** Restart
it — `killall dunst; dunst &` — or just re-login. It's launched once at
session start rather than tracked by systemd, on purpose (see
[Color theming](#color-theming--how-it-actually-works)).
